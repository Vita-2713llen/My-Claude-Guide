## 13. The features the page actually has

**Every block below is gated by the presence sweep** (RUN-02, SKILL.md). Absent
subject → its IDs are ⊘ with the reason, no time spent. The ID after each row is the
instrument row that measures it; `person` rows are closed with `record.cjs`.

### General functionality — always runs

| Перевірка | P | Stage |
|---|---|---|
| Кожне посилання й кнопка мають призначення — немає порожнього, відсутнього чи `#` `href` (LINK-01, LINK-13) | HARD | both |
| Телефон тегом `tel:`, пошта `mailto:`, правильні й ті, що в брифі (LINK-08, LINK-09) | HARD | both |

| Внутрішні посилання проставлені; порожні сторінки створені на старті й злінковані (LINK-01, LINK-03) | HIGH | both |
| Кожен запис у списку веде на свою детальну сторінку (CMS-01, LINK-03) | HIGH | 2 |
| **Рекомендації на детальній сторінці не показують поточний запис.** «Related», «Explore more», «See what else we do», «Інші кейси» на CMS-шаблоні — у фільтрі Collection List **виключено поточний запис** (Slug ≠ Current item або Exclude current item). | Помилка функціоналу веде на кастомну сторінку помилки, а не на дефолтну | MED | 2 |

### FAQ — only if the page has an FAQ section

| Перевірка | P | Stage |
|---|---|---|
| Кожне питання розгортається й згортається; жодне не лишається заблокованим; уся площа рядка клікабельна (INT-01, NAV-13) | HARD | both |
| Одне активне чи кілька — так, як у дизайні | MED | both |
| Відповіді є в розмітці, а не підвантажуються скриптом — інакше їх не бачить ні пошук, ні читач екрана (SEO-11) | HIGH | 1 |
| `FAQPage` schema присутня і побудована з тих самих питань і відповідей — **окрім темплейта для маркетплейсу, де структурованих даних не має бути взагалі**. **Механічно, на опублікованій сторінці (practice rule, 2026-09-16):** розпарсити кожен `script[type="application/ld+json"]`, порахувати `Question` і звірити з кількістю FAQ-пунктів у DOM — на кожній сторінці з FAQ і в кожному CMS-айтемі. Інший тип (`CollectionPage`) рядок не закриває. Пропущено на одному з проєктів на сторінці зі списком послуг, знайшов QA (SEO-11) | HARD | both |
| Питання не дублюються між собою | MED | 1 |
